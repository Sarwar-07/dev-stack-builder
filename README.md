# 🧱 Dev Stack Builder

Dev Stack Builder is a responsive web application designed for developers to discover, compare, and assemble tools into a tailored development stack. Built with React, Vite, and Tailwind CSS.

---

## 🔗 Project Links
- **Live Site:** https://cerulean-hamster-56419e.netlify.app/
- **GitHub Repository:** https://github.com/Sarwar-07/dev-stack-builder

---

## 🛠️ Tech Stack
- **Framework/Library:** React.js (via Vite)
- **Styling:** Tailwind CSS
- **Notifications:** React-Toastify
- **Icons & Data:** Local assets, Devicon, and custom JSON dataset

---

## ✨ Key Features
1. **Interactive Stack Builder:** Add technologies to a dedicated sidebar with real-time counters, duplicate prevention, single-item removal, and batch clearing.
2. **Dynamic UI States:** Add buttons update dynamically to disabled states with visual confirmation once an item is added to the stack.
3. **Toast Notifications:** Contextual alerts for duplicate additions, successful additions, item removal, and clearing the entire stack.
4. **Responsive Design:** Mobile hamburger drawer, adaptive multi-column grid layouts, and sticky navigation header.
